# OneShot 方舟 AI 导演台

输入是有权使用的商品原图和可选事实，不生成商品替身图。产物是 商品可见观察、4 组镜头描述、剧本文案与独立视频 prompt（观察条数依据图片，不固定）。每个镜头单独确认、单独计费，完成后按顺序剪接。

## 1 · 本机启动
解压运行包，Windows 安装 Node 18+、FFmpeg 和 FFprobe，运行 media-service/start.bat，打开窗口显示的 localhost 地址（默认 http://127.0.0.1:41739）。FFMPEG_PATH / FFPROBE_PATH 可指定可执行文件。公开 Pages 仅作入口，不读取私钥、不能发起云任务。FFmpeg 不可用时仍能编写分镜，但不可验证镜头或剪接。

## 2 · 用你已有的 DSH Seedance 插件（默认）
1. 选择原图，建立本机项目。建立项目不计费。点「获取 DSH 看图指令」，交给具备看图能力的会话。它读取该项目的原始 PNG/JPEG，输出 observations 与 4 组 scene/script/prompt。Seedance 本身不是视觉语言模型。如果该会话不能读取实际图片，请换支持视觉的模型或使用下一节的方舟视觉接入点，不能用模板代替。
2. DSH 按交接指令用 host-return.cjs plan 写回结构化 JSON，也可粘贴。项目号与原图 SHA-256 必须相同。刷新项目，逐镜编辑、下载 JSON 然后批准。批准分镜不会创建付费任务。
3. 仅在有权使用且允许发送给方舟时填写同一张商品图的可访问 HTTPS 地址。宿主工具不接受本地路径/data URL；系统不帮你公开图片。署名链接可能含签名，视为敏感信息。该引用由用户核对与原图一致，不宣称远端地址已做哈希验真。
4. 对第 1 镜选择「准备这一镜的 DSH 执行单」。复制页面指令到 DSH；领取操作只能成功一次。核对插件配置中的 Seedance-2.5 接入点；如有预期 ID 不相同，停止并更正。宿主弹出**原生付费确认**后才创建。不要在浏览器导入 DSH 凭据；独立网页不能代点宿主确认。
5. DSH 记录真实 task_id，查询同一任务；成功后下载并通过 host-return.cjs clip 写回。刷新网页可见结果。亦可绑定已有 ID 后选择下载的 MP4 手动导入。此方式根据用户/DSH 回填归属并验证文件可解码，不等同于应用独立查询了方舟。确认云任务已取消、失败或过期时，可登记终态后单独重做。若领取后中断但不清楚是否创建，**先查宿主/方舟任务记录**，不自动重建。
6. 其余镜头亦分别确认。四个镜头文件齐备后点「剪接」，导出 film.mp4、captions.srt 和 storyboard.json；SRT 使用实际片长，不依赖模型烧字。所有镜头有音轨才统一保留音频，否则输出无声版。刷新不重提任务。

## 3 · 可选：本机服务直接调用火山方舟
若要在导演台中直接从原图生成分镜，设置 ARK_API_KEY 和 **ARK_VISION_MODEL**（支持图像输入的豆包模型 ID 或 ep 接入点）。同一个 Key 只有在账户已获授权时才能用于多个模型。视频模型 ID 与视觉模型 ID 不可混用。设置 ARK_VIDEO_MODEL 为已开通的 Seedance-2.5 接入点后，可改选直连视频模式。只读取本机进程环境；不遍历 .dsh、不访问宿主凭据库。也可在私有 deliveries/.ark-private/model.json 填 {"videoModel":"你的ep接入点"} 作为本机视频 ID 提示（不含 Key，不随包分发）。环境变量优先。修改后重启。

方舟北京区域：POST /api/v3/chat/completions 发送原图 data URL 与商品说明；POST /api/v3/contents/generations/tasks 逐镜发送原图、获批提示词、first_frame、5 秒、adaptive；GET 同一任务号查询，成功时由本机服务下载视频，签名链接不发到前端。账户、地区、模型版本的权限及图片规格需以实际方舟响应为准，失败时不切换到合成图片或虚假成片。当前只支持北京区域，不接收任意第三方 API Base URL。

## 数据、费用与恢复
每次视觉分析可能计费；每次视频创建是**一条**可能计费的任务，4 镜通常需要 4 条（失败后重做另计）。没有免费额度或参考价承诺。手动查询不重提任务；创建超时可能已计费，保留 unknown 状态，让操作者核对真实任务号。项目文件位于 deliveries/.ark-private，包含原图、任务单、提示词、下载镜头，交付位于 deliveries/项目号。均不打包、不提交 Git。不要在公共机器共享这些目录；清理需手动删除对应目录，不能撤销已发送给方舟的素材。刷新同源的页面恢复上次项目，另可用 /?project=项目号。上传前确认素材的版权与隐私。视频生成可能改变外观或文字，运营需逐镜看过后再发布。

官方文档：[视频创建](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh) · [按任务号查询](https://docs.volcengine.com/docs/ark/get-video-generation-task-api?lang=zh)。本次接口契约/本机剪接验收采用明确标注的测试响应与临时视频夹具，非真实模型生成验收。
