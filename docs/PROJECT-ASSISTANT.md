# 项目广告助手

在本机打开 AI 制片工作台 → 02 图文分镜 → 展开「项目广告助手」。它使用已配置的 OpenAI 兼容图文模型的 Chat Completions / function tools 能力；本轮对话只发文字，不重传原图。不支持工具调用的供应商或部署会失败，不静默退回离线演示。

**只读**：例如“这四镜中哪些还在等待我批准？”助手可读取本项目商品介绍、模型已有的观察、某一镜的已保存稿、本机记录的生成状态。状态不是实时云端查询。

**授权单镜提案**：选择“仅向第 2 镜提候选”，输入“保持原卖点，让包装上的净含量看得更清楚”。确认本轮可能的文字模型费用后，助手必须先读取商品依据和第二镜原稿才可暂存候选。成功后从“比较第 2 镜候选”去现有编辑区采用或丢弃。不会覆盖已有候选，不修改正式稿，不能批准、发布、查外部链接或下发视频任务。问题与授权镜头不一致时，以选择器为写权限边界。

**执行记录与恢复**：每轮最多 4 次模型请求、5 次工具调用、约 120 秒模型循环；无自动重试。记录里显示用户问题、模型回复、请求次数、工具名/镜号与是否成功。一个项目保留最近 20 轮，模型上下文最多带入最近 4 轮成功对话的截短文字，以本轮工具返回为准。只保存在本机项目文件；没有新增托管服务、账号系统或数据库。中断可能已计文字费用；查看记录，同编号重复请求不会主动重跑（在保留窗口内）。失败不提交暂存候选。

**参考**：[coder-thor/genshin-agent](https://github.com/coder-thor/genshin-agent/tree/32dcad00856c16cc4455b787359a2aa70c09a663) 的有界工具循环、工具观察回传与会话续接。此处是适配广告审批约束的独立实现，未复制游戏业务、登录系统或日志中的原始工具参数。
