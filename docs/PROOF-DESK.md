# 纸白校样室 · 跨页设计

保留纸白样刊，不采用炭黑监看室；比较三款浅色工作台后，选定纸白校样室。设计调研依据：[UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill/tree/2de1134dc4d1cfe112934611ae5803ae17a1bd7e/.claude/skills/ui-ux-pro-max)。只参考公开指南，不运行上游安装脚本。

六个正式页面：展厅、素材、分镜、审查、交付、配置。暖纸底与浅色表单区分阅读面/可填写面。衬线标题、细线页眉、刊号/步骤编号贯穿四步及设置；钴蓝突出当前选择和主要动作。镜头状态有文字及符号，失败、未知、已就绪不只靠颜色。手机导航三入口同排，正式页面的主要操作与下载控件最小高度 44px。保持系统减少动效和键盘焦点。

本次仅改视图，不改模型、项目存储、权限或计费。任务流、键盘选镜、减少动效、手机无横向溢出、真实测试视频剪接及无付费请求均在隔离项目验证。测试画面不是付费模型生成结果。
