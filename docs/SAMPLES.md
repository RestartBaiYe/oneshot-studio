# 预置样例来源

三份案例均由本项目脚本建立，不使用第三方品牌素材或外部素材站。scripts/sample-art.cjs 定义原创矢量商品、金属/纸袋层次、光照与阴影；product.svg 为代码自绘商品示意，product.png 为浏览器实际栅格化结果；规格、价格为演示输入，不代表真实商品承诺。样例无音轨。0.5版重新生成三个样例，正常两段各288帧、12秒，加入镜头运动及三次交叉淡化。素材自身不烘焙版式标题，避免与视频字幕叠字。

- commute：一次规则审查后批准，FFmpeg生成12秒通勤杯短片。
- coffee：主动注入“24小时”未提供主张，退回后第二轮通过；最终文案采用离线模板，不宣传为优秀创意或模型生成。报告记录0次模型调用。
- blackframe：在咖啡片3.00–3.75秒插入黑场，再用本机API检测。实际测得3.00–3.791667秒，差异来自帧时间边界。

重建：安装开发依赖，启动本机服务，在同一仓库运行 npm run samples:build。脚本分别使用隔离页面绘制素材，实际运行 Agent 与审批，再请求真实编码和检查。不会调用收费模型；会覆盖随包样例，输出也会留在本机 deliveries/，后者不入库。

预置播放/报告/下载使用独立样例区；载入新任务仅载入原图、事实或待检视频，不填入预置审批/工具状态/交付结果。商品图是示意而非实物摄影；本项目不附加第三方字体的再分发权利。
