- tests/runtime.cjs：11项，包括默认拒绝、错误停止、无静默降级、三轮上限、等待人工不计主动运行预算。

- 重新上传带黑场测试片，实际检测3.00–3.791667秒黑场；报告保留、原视频已删除。输入改变时旧结果、审批、下载和播放器清空。
- Host、Origin、静态路径、错误文件编码、健康检查继续服务等防护检查通过。
- tests/interaction.cjs：样例弹窗焦点/Escape、审批焦点与拒绝、批处理导航隔离、指针反馈、运行时切换减少动画、移动端停止入口、样例503载入失败后可重试。页面错误0。
- scripts/build-samples.cjs：通过当前新入口重新实际构建三份样例；商品图隔离页面绘制；模型调用0。

完整机器可读结果见 acceptance.json。测试环境为本机 Windows、Edge、Node、FFmpeg9.0.2；没有重新调用付费模型。本轮模型错误测试采用模拟响应，不能算真实模型验收。

## 发现 → 修复 → 复核

| 问题 | 处置 |
|---|---|
| 第二次字幕/审查工具显示“等待” | 按调用位置对应执行记录；13条含重复工具的记录均完成。 |
| 修改输入仍保留Agent旧结果 | 清空result，脚本/视频链接与审批一起失效。 |
| 结束时异步跳转覆盖用户刚切换页面 | 加导航版本校验；批处理不被项目自动跳转打断。 |
| 示例封面首帧未解码、手机标题割裂 | 关键图片优先加载并测试decode，标题语义片段不拆开。 |
| 含视频的样例弹窗Tab可移出 | 首尾焦点循环；Escape关闭并恢复来源焦点。 |
| 系统动态启用减少动画后仍有4项入场动画 | 显式取消所属Web Animations，测试运行动画数为0。 |
| 案例程序清空产生与新任务矛盾的短暂提示 | 载入时移除程序清空提示，使用当前任务状态。 |

一次完整测试曾在载入黑场案例等待时超时；独立载入和后续整链路重跑通过。后续交互测试明确复现并修复了延后导航覆盖问题。最终源码的全套运行时、UI媒体和交互测试再次通过。

## 设计参考与边界

沿用用户给定的 MotionSites、Aceternity、Showreel、Uiverse、React Bits、Anime.js 方向，采用作品优先、编辑式层次、卡片反馈和克制动效。前轮实访前五个可达参考中Uiverse受到403验证，未复制其组件；本轮未声称再次浏览全部站点。实现为现有原生CSS/Web Animations，无新UI框架或复制商业模板。

没有发现尚未处置的确定性本轮缺陷。业务验证、开放式规划、生成式视频、配音、多用户和云端能力不在本次已完成能力内，见RUBRIC与ARCHITECTURE。公开仓库排除私人表单、联系方式、用户上传、密钥与历史临时文件。
