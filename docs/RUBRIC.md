# AI+Agent 评分复核：证据，不是自评分

依据《虹桥国际科技周黑客松 三赛道评审规则与评分标准 V1.0》，2026年11月20—22日，AI+Agent 场次11月21日；四项各25分，现场演示4分钟、问答1–2分钟。下表对照实际能力，不预测得分。

| 维度 | 当前可展示证据 | 仍然存在的差距 |
|---|---|---|
| 任务定义与场景价值 25 | 电商运营在上新/促销时输入事实与素材，得到脚本、检查、人工批准、短片与配套文件；三个案例说明触发条件；成功标准是本次文件可播放、报告可复查、未批准不可导出。 | 尚无真实商家访谈、付费、节时对照或线上经营数据；不能把演示价值等同商业验证。 |
| 任务完成度 25 | 浏览器真实起草/规则检查/有限修订/批准，本机真实 H.264 编码与回检；修订案例有两轮、13条工具记录；失败提示、旧结果失效、测试覆盖。 | 公共网页独立运行不能编码；现场需预装 Node、FFmpeg、字体。预置成片只能帮助理解，不能作为现场运行证据。 |
| 可落地性 25 | 本机启动路径、权限/文件上限/源文件清理、内存Key、可拒绝、错误停止、无自动发布；完整源代码和可重建样例。 | 无业务平台接入、多用户鉴权、持续任务、生产监控；成本仅显示实际模型调用统计，不承诺固定价格。 |
| Agent 技术实现 25 | 固定计划白名单、工具输入/输出校验、本地历史、预算、模型失败不降级、失败检查回馈修订、逐次工具证据、审批边界。 | 无MCP、多Agent、自主工具选择；离线模式是规则流程，不代表模型推理；本轮未重新验收真实付费模型。 |

## 演示红线

预置视频、商品示意图和报告处处标注预置来源；不写入本次 Agent 结果。现场至少实时运行一次修订/审批和一次本机制作或回检。不得宣称本产品做了视觉语义、真假、广告法或生成式视频判断。无虚构用户证言、使用量、耗时节省或预测得分。

## 可复核入口

tests/runtime.cjs：11项规则/权限/错误回归；tests/ui.cjs：真实文件和浏览器链路；tests/interaction.cjs：键盘/动效/隔离/错误恢复；samples/*/report.json：预先实际构建的样例证据；docs/ACCEPTANCE.md：本轮验收及问题处置。
